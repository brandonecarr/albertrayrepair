# Work gallery photos

Drop Albert's job photos into this folder and they appear automatically in the
"Our Work" section on the homepage — no code changes needed.

- Supported: `.jpg` / `.jpeg` / `.png` / `.webp` / `.avif`
- Order: files are shown sorted by filename, so name them `01-...`, `02-...`,
  etc. to control the order (e.g. `01-deck.jpg`, `02-drywall.jpg`).
- Optional caption: put it in the filename after a ` -- ` separator, e.g.
  `03-tile-bathroom -- Master bath tile & grout.jpg` shows the caption
  "Master bath tile & grout". Underscores/dashes in the name become spaces.
- The section hides itself automatically when this folder has no images.

Tip: photos taken on a phone are large — that's fine, Next.js optimizes and
resizes them on the fly when served.
